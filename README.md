# UniConnect Development Notes

## About UniConnect
UniConnect is a lightweight project management application designed for software engineering student teams to improve on collaboration and communication.

*** Tech Stack: ***
- Java
- Spring Boot
- MySQL
- C#
- .NET MAUI
